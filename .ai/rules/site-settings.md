# Site Settings

## Site settings are contact and boutique only
Site settings only store contact channels, Instagram, and boutique coordinates. Do not add a CMS announcement or TranslatesWithDeepL on SiteSetting; the topbar uses the i18n key `Eerste Editie — Beperkt tot 100 Stuks`. The admin form uses AdminResourceShell at full width like legal and SEO edit pages.
